# 오늘의 TODO에 기록하기

사용자가 지정한 할 일을 오늘 Daily 노트의 `# TODO` 섹션에 추가합니다.

- 사용자의 현지 날짜를 확인하고 `~/wiki/Journal/Daily/YYYY-MM-DD.md` 노트를 엽니다.
- Daily 노트가 없거나 정확히 `# TODO`인 제목이 없으면 사용자에게 알리고 멈춥니다. Daily 노트나 섹션을 새로 만들지 않습니다.
- 할 일이 구체적으로 전달되지 않았다면 먼저 내용을 물어보고 파일을 수정하지 않습니다.
- 각 할 일을 `- [ ] <할 일>` 형식의 별도 체크박스로 기록합니다. `# TODO`에 실제 할 일이 있으면 그 뒤에 추가하고, 내용 없는 `- [ ]` 자리표시자만 있으면 첫 할 일로 바꿉니다.
- 기한이나 우선순위는 사용자가 지정한 경우에만 해당 할 일에 포함합니다. 지정하지 않은 값을 추정하지 않습니다.
- TODO 섹션 밖의 내용과 기존 항목은 수정하지 않습니다.

## 완료 보고

추가한 항목과 Daily 노트 경로를 보고합니다.
